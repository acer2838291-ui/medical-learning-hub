## 導入到本專案的設計決策

- 採暖米白背景、深綠灰文字、柔和綠連結及陶土色重點的低飽和配色。
- 保留 Starlight 預設的文章目錄、搜尋、明暗模式與響應式導覽，再用 CSS Variables 調整視覺。
- 不採漸層、重陰影或高彩度大色塊。
- 以約 49 rem 作文章最大寬度初始值，正式比對需待本機瀏覽器預覽。
- AA 對比度仍需用實際前景／背景配對工具驗證；目前色值屬估值，不宣稱通過。

## 尚待補測

完整頁長桌機截圖、390 px 手機截圖、手機側欄展開、實際 hover／active 狀態、右側目錄滾動行為、Computed Style 精確值、字體實際名稱與 WCAG 對比度。
