# Publication Safety Review

Before writing to `src/content/docs/`, `src/pages/`, `public/` or any Git-tracked public content:

1. Identify the exact origin, license and reuse conditions for every third-party passage, slide, PDF, table, question, image or screenshot. An accessible URL is not proof of an open license. Unknown rights mean do not publish the source material.
2. Check for patient identifiers, unpublished research, institutional reports, private messages, access tokens and personal learning data. Keep these outside this public repository.
3. Check whether medical claims and numbers are supported by the actual source. Record Source Type, title, edition/year, chapter/section/page, URL/DOI/PMID, last-checked date, verification status and permission. Do not call generated text or metadata-only screening an independently verified finding.
4. If preparing a TriNetX-related article, keep cohort definitions, AA values and analysis versions distinct; do not imply LIVE verification from a methodology checklist.
5. `draft: true` is optional metadata and does not make GitHub files or Pages private. A public commit is public history.
6. For AccessMedicine/McGraw Hill content, review the specific product terms and institution agreement. Unless applicable written authorization explicitly covers AI-agent access and the exact processing, do not enter restricted content with an AI browser, scrape, batch download, capture screenshots, submit passages to external AI, generate extensive translations, or publish derivatives. School access alone is not AI permission.
7. Distinguish publisher-operated AI Features from third-party AI tools. Product AI language is not general permission for outside agents.
8. Report pass/fail/unknown decisions for the actual content. Stop publication when essential authorization or source evidence is missing; use attributed open-license sources, public bibliographic metadata, official links and original explanations where appropriate.

This skill does not grant permissions to publish and does not override `AGENTS.md`.
