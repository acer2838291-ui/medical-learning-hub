# Medical Slide Notes

Use when the user supplies slides, PDFs, screenshots or lecture text and requests notes, transcription, translation or exam emphasis.

- Determine source scope from the current instruction. When asked to use only the slides, **do not add outside information**.
- Preserve original English terms, abbreviations, all numeric thresholds, dates and source page labels; distinguish verbatim material from translation and editorial organization.
- Add Traditional Chinese translation/explanation separately. For unclear text, mark `[原文不清]` rather than guessing.
- Mark original red-font text, numeric traps, comparison tables and teacher-specified emphasis; do not claim a topic was highlighted if evidence is absent.
- Create comparison tables only from material supported by the supplied sources.
- Add a separate English exam-answer summary only for courses or tasks that request it.
- Distinguish physician board and public-health examination materials. Never call generated questions official past papers without an authoritative source.
- Report pages actually checked; a partially scanned document is not a fully extracted one.
- **Publication boundary:** output private notes first if permissions are uncertain. Never copy raw lecture material or restricted textbooks to this public repository. `draft: true` is not access control.
